# DESIGN.md — 두목쿼카의 기록 (블로그 포스팅 아카이브)

Claude가 만든 네이버 블로그 포스팅 아티팩트를 한곳에 모아 두는 사이트다.
카드를 누르면 그 포스팅 아티팩트(claude.ai/artifact/…)가 새 탭으로 열린다.

## 1. 출발점: 네이버 블로그에서 가져온 것, 가져오지 않은 것

| 가져온 구조 | 우리 식으로 바꾼 점 |
|---|---|
| 상단 블로그 타이틀 영역(스킨) | 사진 스킨 대신 네이버 초록 띠 한 장. 블로그 이름과 글 수만 |
| 왼쪽 프로필 + 카테고리 메뉴(개수 표시) | 프로필은 글자 두 줄, 카테고리는 `이름 (n)` 그대로. 화면이 좁으면 가로 칩으로 |
| 앨범형 / 목록형 보기 전환 | 같은 두 보기. 선택된 쪽이 초록 버튼. 기억은 브라우저에만(localStorage) |
| 새 글 `N` 표시 | 올린 지 3일 이내 글에만 초록 `N` |
| 블로그 내 검색 | 제목·요약·카테고리를 즉시 거르는 검색칸 하나 |

가져오지 않은 것: 이웃·공감·댓글 수, 위젯, 배너, 방문자 수, 네이버 로고.

## 2. 색

**네이버 초록(#03C75A)이 주인공이다.** 띠·선택 버튼·N 표시·목록 머리 밑줄에 쓴다.
초록 바탕 위 글자는 흰색이 아니라 짙은 초록(#06281A)으로 써서 읽히게 한다.
흰 바탕 위 초록 글자(카테고리, 선택 메뉴)는 대비를 위해 한 단계 짙은 #00873C를 쓴다.
아쿠아블루·오렌지는 쓰지 않는다. 그라디언트도 쓰지 않는다.

| 토큰 | 라이트 | 다크 | 쓰임 |
|---|---|---|---|
| `--brand` | `#03C75A` | `#03C75A` | 타이틀 띠, 선택 버튼, N, 목록 머리 밑줄 |
| `--on-brand` | `#06281A` | `#06281A` | 초록 위 글자 |
| `--accent` | `#00873C` | `#4BE38F` | 카테고리 라벨, 선택된 메뉴, 포커스 윤곽 |
| `--bg` | `#FFFFFF` | `#0F1412` | 페이지 바탕 |
| `--surface` | `#F4F7F5` | `#17201B` | 행 hover |
| `--fg` | `#1A1F1C` | `#E9F0EC` | 본문 글자 |
| `--muted` | `#68706B` | `#93A098` | 날짜, 요약 |
| `--line` | `#E5E8EB` | `#25302A` | 구분선 |
| `--ink` / `--lav` | `#0F2A1E` / `#6FF0A8` | 같음 | 글자 표지 바탕 / 제목 |

## 3. 글꼴

- 본문·제목: **IBM Plex Sans KR** (400/500/600/700), 대체 `Pretendard, Apple SD Gothic Neo, Malgun Gothic, sans-serif`
- 날짜·숫자: **IBM Plex Mono** (`tabular-nums`)
- 크기 단계: 12 / 13 / 15 / 17 / 22 / 30px. 제목은 `text-wrap: balance`.

## 4. 레이아웃

- 최대 폭 1120px. 데스크톱은 `사이드바 232px | 글 목록` 2단.
- 760px 아래에서 1단. 사이드바 카테고리는 가로 스크롤 칩으로 바뀐다.
- 좌우 여백은 `max(16px, env(safe-area-inset-*))`.
- **앨범형**: 썸네일 16:9, 3열 → 2열(980px↓) → 1열(560px↓). 썸네일 아래 카테고리·날짜, 제목 2줄, 요약 2줄.
- **목록형**: 한 줄에 `카테고리 | 제목 | 날짜`. 네이버 ‘목록 열기’ 느낌.

## 5. 카드 규칙

- 테두리·그림자 없음. 썸네일만 6px 둥근 모서리.
- hover: 썸네일 1.02배, 제목 밑줄. 키보드 포커스는 2px `--accent` 윤곽.
- 썸네일이 없는 글은 **글자 표지**: 짙은 초록 `--ink` 바탕, 왼쪽 위 `두목쿼카의 기록`, 가운데 제목(민트 `--lav`), 오른쪽 아래 카테고리.
- 썸네일은 포스팅 표지 GIF의 한 프레임을 800×450 WebP로 저장한다. 힉스필드 생성 이미지는 썸네일로 쓰지 않는다.

## 6. 문구

- 사이트 이름: `두목쿼카의 기록`, 부제: `Claude와 함께 쓴 블로그 포스팅 보관함`
- 버튼·라벨은 짧게: `앨범형`, `목록형`, `전체보기`, `검색`.
- 글이 없을 때: `아직 이 카테고리에 올린 글이 없어요.`

## 7. 등록 방법 (Claude가 하는 일)

1. 포스팅 표지 GIF에서 한 프레임을 뽑아 `thumbs/<아티팩트ID>.webp`(800×450)로 저장한다.
2. `posts.json` 배열에 한 항목을 더한다. 순서는 상관없다(날짜순으로 정렬해 그린다).

```json
{"id":"<아티팩트ID>","date":"YYYY-MM-DD","category":"사용법",
 "title":"포스팅 제목","excerpt":"한두 문장 요약(본문 문장에서)",
 "url":"https://claude.ai/artifact/<아티팩트ID>","thumb":"thumbs/<아티팩트ID>.webp"}
```

3. 같은 사이트를 다시 배포한다.

카테고리는 이미 있는 것 중에서 고른다: `소식` `칼럼` `일상` `사용법` `개발기` `후기` `AI 개념극장`.
새 카테고리가 필요하면 그냥 새 이름을 쓰면 사이드바에 자동으로 생긴다.
